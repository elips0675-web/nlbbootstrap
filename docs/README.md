## 2. Архив

`archive/README.md` — индекс исторических заметок. В архив попадает то, что
перестало быть правдой: старые варианты установки, отвергнутые макеты,
черновики текстов.

## 3. Гигиена документации

- Новые правила не добавляются в `.txt`-файлы. `.txt` — только журнал и
  бэклог.
- Если файл не упомянут в `AGENTS.md`, `README.md` или здесь — он архив.
- Каждый пункт бэклога содержит `file:line` или точный путь в админке. Пункт
  без доказательства не принимается.
- Закрытый пункт удаляется из `Что доделать.txt` целиком и попадает одной
  записью в `Что сделано.txt`.
- Числа (размеры, количество файлов, версии) берутся из кода/каталога, а не
  перепечатываются из старых отчётов.
- Числа и ссылки проверяются гейтами, а не глазами: `node tools/check-doc-numbers.mjs`
  (факты — `php db/stats.php --json`) и `node tools/check-doc-refs.mjs`
  (файл, строка, якорь рядом). Оба падают и при расхождении, и при попытке
  ослабить проверку — исчезнувшее утверждение или отсутствие PHP это exit 1.
