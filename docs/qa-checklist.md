# QA-чеклист

Две части: **A** — что можно проверить локально по статическому демо
`preview/`, **B** — что проверяется только на живом Битриксе. Пункты B нельзя
закрыть на машине без PHP/MySQL — это фиксируется в `Что доделать.txt`.

## A. Локально (превью)

Из каталога репозитория запустите `php -S 127.0.0.1:8791 -t preview` и откройте
`http://127.0.0.1:8791/`. Не открывайте `preview/index.html` по `file://`:
ссылки на каталоги и service worker там не работают. Проверяйте в Chrome/Edge и,
если есть, в Firefox.

### A1. Загрузка

- [ ] нет 404 в консоли (вкладка Network);
- [ ] нет ошибок JS в консоли;
- [ ] Bootstrap CSS и `styles.css` применились (кнопки скруглённые, hero тёмный);
- [ ] системный шрифт отображается без скачивания внешних файлов;
- [ ] изображения hero, новостей, печати видны;
- [ ] `/services/`, `/news/`, `/events/`, `/printing/`, `/books/`,
  `/collections/`, `/contacts/` открываются по прямым адресам.

### A2. Шапка

- [ ] топбар виден на ≥ 992px и скрыт на мобильном;
- [ ] логотип и подпись не переносятся;
- [ ] пункты меню имеют hover-фон;
- [ ] активный пункт подсвечен, в том числе на внутренних страницах;
- [ ] меню ведёт на страницы (`/news/`, `/services/`…), а не на якоря `#…`;
- [ ] иконки поиска/уведомлений/кабинета кликабельны;
- [ ] при прокрутке появляется тень у шапки;
- [ ] шапка остаётся сверху (sticky) и не перекрывает контент.

### A3. Hero-карусель

- [ ] 3 слайда, автопрокрутка ~7 секунд;
- [ ] индикаторы переключают слайды;
- [ ] стрелки работают на десктопе и скрыты на мобильном;
- [ ] текст читаем на каждом слайде (контраст);
- [ ] кнопка ведёт на `#services`/`#events`;
- [ ] на мобильном высота hero не обрезает заголовок.

### A4. Секции

- [ ] услуги: 8 карточек, 1/2/3 в ряд на 360/768/1440;
- [ ] печать: скроллер листается кнопками и пальцем, кнопки блокируются на краях;
- [ ] события: 3 карточки, дата в бейдже, метаданные с иконками;
- [ ] новости: 4 карточки, текст обрезан в 2 строки;
- [ ] сувениры: 6 карточек наборов, иконки слева, число подарков градиентом;
- [ ] партнёры: 5 плиток, hover;
- [ ] CTA-баннер: две кнопки, на мобильном в столбик;
- [ ] reveal-анимация срабатывает при прокрутке (и отключена при
      `prefers-reduced-motion`).

### A5. Подвал

- [ ] 4 колонки на десктопе, 2 на планшете, 1 на мобильном;
- [ ] ссылки «Читателям»/«Услуги» ведут на якоря;
- [ ] телефон и e-mail кликабельны;
- [ ] форма подписки: пустой e-mail → ошибка, корректный → уходит (в превью
      никуда не уходит — это нормально);
- [ ] соцсети открываются в новой вкладке;
- [ ] копирайт с текущим годом.

### A6. Модалки и виджеты

- [ ] поиск открывается по кнопке и `Ctrl+K`, фокус в поле;
- [ ] поиск закрывается по крестику, `Esc`, клику по фону;
- [ ] FAB раскрывается, пункты появляются каскадом;
- [ ] FAB закрывается по `Esc` и клику вне;
- [ ] «ИИ-помощник» в меню FAB открывает окно чата, меню при этом сворачивается;
- [ ] в чате есть приветствие и четыре быстрых ответа, клик по ним отправляет
      сообщение; на «привет» и «адрес» приходят ответы, на «Позвать оператора» —
      ответ оператора;
- [ ] поле ввода получает фокус после открытия, `Esc` и крестик закрывают чат,
      история сохраняется при повторном открытии;
- [ ] чат не перекрывает кнопку «+» и «наверх» ни на 360px, ни на десктопе;
- [ ] «наверх» появляется после ~480px и плавно скроллит;
- [ ] модалка обратной связи: валидация e-mail/сообщения/согласия;
- [ ] модалка реквизитов открывается (если есть кнопка — сейчас только в
      Bitrix-версии).

### A7. Адаптив

Проверить ширины: **360, 390, 768, 1024, 1440, 1920**.

- [ ] нет горизонтального скролла;
- [ ] текст не выходит за карточки;
- [ ] карточки в одной колонке не вылезают за неё и не наезжают на подвал
      (`/feedback/`, `/subscribe/`, `/contacts/` — там по две карточки в колонке);
- [ ] кнопки не наезжают друг на друга;
- [ ] меню-бургер работает и закрывается после клика;
- [ ] FAB не перекрывает «наверх» и контент.

### A8. Доступность

- [ ] все иконочные кнопки имеют `aria-label`;
- [ ] активный пункт меню — `aria-current="page"`;
- [ ] модалки: `aria-labelledby`, `aria-hidden`, фокус-трап Bootstrap;
- [ ] `Tab` проходит по всем интерактивным элементам, фокус виден;
- [ ] изображения имеют `alt` (декоративные — пустой);
- [ ] заголовки идут по порядку (h1 → h2 → h3);
- [ ] при `prefers-reduced-motion` нет анимаций.

### A9. Печать

- [ ] `Ctrl+P`: шапка, подвал, FAB, стрелки скрыты;
- [ ] hero без фоновой картинки, текст чёрный;
- [ ] контент не обрезан.

### A10. Структурный чекер

```powershell
node tools/check-template.mjs
node tools/check-docs.mjs
```

Оба должны завершиться с кодом 0.

## B. На живом Битриксе

Выполняется после установки (`installation.md`). Каждый пункт — с указанием,
где смотреть.

### B1. Установка

- [ ] шаблон есть в списке **Настройки → Настройки продукта → Сайты → Список
      сайтов → Шаблон сайта**;
- [ ] после выбора и очистки кеша главная открывается в новом оформлении;
- [ ] в исходном коде есть `bootstrap.min.css` и `styles.css` без 404;
- [ ] админ-панель видна сверху;
- [ ] `local/templates/nlb_bootstrap/` доступен на чтение, но не на запись
      всем.

### B2. Меню

- [ ] тип `top` создан;
- [ ] пункты ведут на существующие страницы;
- [ ] активный пункт подсвечивается на своей странице;
- [ ] при удалении пункта из админки он исчезает после сброса кеша;
- [ ] демо-меню не показывается (иначе тип `top` пуст).

### B3. Хлебные крошки

- [ ] на внутренней странице видны крошки;
- [ ] на главной их нет;
- [ ] последний элемент без ссылки;
- [ ] крошки соответствуют пути (раздел → страница).

### B4. Компоненты

- [ ] новости выводятся карточками, дата и картинка на месте;
- [ ] пагинация работает;
- [ ] детальная новость открывается, текст в `.bitrix-content`;
- [ ] события выводятся с датой и категорией;
- [ ] поиск находит новость по слову;
- [ ] подписка отправляет письмо, подтверждение приходит;
- [ ] обращение появляется в `requests`, письмо приходит, в журнале есть запись;
- [ ] бронь появляется в `bookings`, занятый слот не принимается;
- [ ] заказ появляется в `orders` с товаром, артикулом и количеством;
- [ ] вход/выход работают, кнопка меняется на «Кабинет».

### B5. Производительность

- [ ] главная отдаётся < 1.5 c на локальном стенде (без кеша — < 3 c);
- [ ] после прогрева кеша TTFB < 300 ms;
- [ ] картинки < 300 КБ каждая;
- [ ] нет внешних блокирующих запросов (шрифты системные, CDN нет);
- [ ] `gzip`/`brotli` включены на сервере.

### B6. Безопасность

- [ ] `local/` не отдаёт `.php` как текст;
- [ ] в `robots.txt` закрыты `/bitrix/`, `/db/`, `/tools/`, `/search/`, `/auth/`, `/personal/`;
- [ ] формы защищены CAPTCHA;
- [ ] в шаблоне нет реальных паролей/ключей;
- [ ] права на файлы 644/755;
- [ ] бэкап сделан до установки.

### B7. Кеш

- [ ] после правки `header.php` изменения видны после сброса кеша;
- [ ] `MENU_CACHE_TIME` не мешает обновлению меню;
- [ ] при выключенном кеше сайт работает (проверка на стенде).

## C. Регресс before/after

Перед сдачей:

1. Сохраните скриншоты главной (1440px и 390px) в `docs/archive/` или во
   внешнем хранилище.
2. После правок сравните: не сдвинулись ли секции, не пропали ли иконки.
3. Проверьте, что количество карточек в каждой секции совпадает с ожидаемым.
4. Прогоните `node tools/check-template.mjs` и `node tools/check-docs.mjs`.

## D. Что считается дефектом

| Симптом | severity |
|---|---|
| 404 на CSS/JS/картинку | critical |
| ошибка JS в консоли | critical |
| горизонтальный скролл на 360px | major |
| нечитаемый текст (контраст < 4.5:1) | major |
| форма отправляется в никуда | major |
| битая ссылка в меню/подвале | major |
| иконка без `aria-label` | minor |
| сдвиг на 2–4px | minor |
| другое начертание шрифта из-за fallback | info |

## E. Отчёт

В `Что сделано.txt` фиксируется:

- дата и этап;
- что проверено (A/B, какие пункты);
- что **не** проверено и почему;
- команды гейтов и их код возврата.
