# Контент и структура сайта

Шаблон не создаёт страницы. Ниже — минимальный набор, при котором сайт
выглядит и работает как задумано.

## 1. Структура разделов

```
/                         главная (landing)
├── /news/                список новостей
│   └── /news/<code>/     детальная новость
├── /events/              афиша
│   └── /events/<code>/   детальная события
├── /services/            услуги
├── /printing/            печать и копирование (37 услуг)
├── /books/               каталог сувениров и мерча
├── /collections/         подарочные наборы
├── /map/                 интерактивная карта
├── /rules/               правила пользования
├── /about/               о библиотеке
├── /contacts/            контакты
├── /search/              результаты поиска
├── /subscribe/           подписка
├── /feedback/            обратная связь
├── /auth/                вход, регистрация, восстановление
├── /personal/            личный кабинет
├── /privacy/             политика конфиденциальности
├── /terms/               условия использования
└── /sitemap/             карта сайта
```

Разделы создаются в **Контент → Структура сайта**: «Добавить раздел»,
затем в разделе — «Добавить страницу» (файл `index.php`).

## 2. Главная страница

Порядок секций фиксирован макетом. Менять местами можно, но тогда проверьте,
что якоря меню (`#services`, `#events`, `#news`, `#collections`) остались на
месте.

| Секция | Заголовок (пример) | Источник |
|---|---|---|
| Hero | «Мир знаний нового поколения» | 3 слайда, статика |
| Услуги | «Комфорт и технологии для вашего обучения» | статика / инфоблок |
| Печать | «Каталог печатных услуг» | инфоблок `printing` |
| События | «Предстоящие мероприятия» | инфоблок `events` |
| Новости | «Новости» | инфоблок `news` |
| Сувениры | «Готовые подарки с символикой библиотеки» | статика / инфоблок `collections` |
| Партнёры | «Нам доверяют» | статика |

Тексты hero (3 слайда):

1. «Мир знаний нового поколения» — 500 000 книг, цифровые ресурсы,
   инновационные пространства.
2. «Технологии для вашего роста» — коворкинг, компьютерные залы, Wi-Fi.
3. «События, которые вдохновляют» — лекции, мастер-классы, встречи.

## 3. Инфоблоки

Создание: **Контент → Инфоблоки → Типы инфоблоков** → тип, затем
**Контент → Инфоблоки → <тип> → Добавить инфоблок**.

### `news` — Новости

| Поле | Тип | Обязательно |
|---|---|---|
| Название | строка | да |
| Символьный код | строка | да (для ЧПУ) |
| Анонс | текст | да |
| Детальный текст | текст | да |
| Картинка анонса | файл | да |
| Дата активности | дата | да |
| `AUTHOR` | строка | нет |
| `TAGS` | список | нет |
| `READ_TIME` | строка | нет |

### `events` — События

| Поле | Тип | Обязательно |
|---|---|---|
| Название | строка | да |
| Анонс | текст | да |
| Картинка анонса | файл | да |
| Дата активности | дата/время | да |
| `DATE` | дата/время | да |
| `PLACE` | строка | да |
| `CATEGORY` | список | да |
| `SEATS` | число | нет |
| `REGISTER_URL` | строка | нет |

Значения `CATEGORY`: `literature`, `kids`, `tech`, `lecture`.
Цвет бейджа выбирается по коду (см. `bitrix-integration.md`, п. 5).

### `printing` — Печатные услуги

| Поле | Тип | Обязательно |
|---|---|---|
| Название | строка | да |
| Анонс | текст | да |
| Картинка анонса | файл | да |
| `PRICE_FROM` | число | да |
| `ICON` | строка | да (`printer`, `scan`, `card`, `file`, `package`, `image`, `cup`, `book`) |
| `COLOR` | список | нет (`primary`, `green`, `sky`, `pink`, `orange`) |

Девять карточек из демо: печать и копирование, сканирование, переплёт,
визитки, брошюры, широкоформат, холст, кружки, футболки. Полный каталог —
37 позиций (`db/config/data/printing.php`), включая фото, сувениры и
фирменные материалы.

### `books` — Каталог сувениров и мерча

Код инфоблока и разделов оставлен книжным, чтобы не ломать адреса `/books/`
и миграции; названия свойств и разделов описывают сувениры.

| Поле | Тип | Обязательно |
|---|---|---|
| Название | строка | да |
| `AUTHOR` — материал | строка | да |
| `YEAR` — размер | строка | нет |
| `ISBN` — артикул | строка | нет |
| `PUBLISHER` — упаковка | строка | нет |
| `PAGES` — вес, г | число | нет |
| `SHELF` — состав | строка | нет |
| `AVAILABLE` — наличие | список | да |
| `PRICE` — цена, ₽ | число | да |

Разделы: Брелоки, Посуда и фарфор, Одежда, Канцелярия, Магниты и открытки,
Аксессуары. В демо — 24 товара, включая фарфор, шопперы, футболки, блокноты,
ручки, брелоки и товары для автомобиля.

### `collections` — Подарочные наборы

| Поле | Тип | Обязательно |
|---|---|---|
| Название | строка | да |
| Анонс и описание | текст | да |
| `COUNT` — предметов в наборе | число | да |
| `COLOR` | список | нет |
| `ICON` | строка | нет |

Шесть наборов: для коллег, дома, «Читаю», путешествий, детей и на память о
Минске.

## 4. Наполнение: минимальный объём

Чтобы сайт не выглядел пустым, до сдачи нужно:

- 3 hero-слайда с реальными фото библиотеки;
- 8 премиальных услуг с иконками;
- 37 печатных услуг с ценами;
- 3 ближайших события;
- 8–12 новостей;
- 24 сувенира с ценами и 6 подарочных наборов;
- 5 партнёров (текст или логотип);
- контакты, режим работы, схема проезда;
- политика конфиденциальности и условия использования.

## 5. Тексты и tone of voice

- Обращение — «вы», без канцелярита.
- Заголовки — до 60 символов, без точки.
- Анонс — 1–2 предложения, до 180 символов.
- CTA — глагол + объект: «Записаться на лекцию», «Смотреть каталог».
- Числа — с пробелом-разделителем: «150 000+», «5 500 ₽».
- Не использовать CAPS для целых фраз (только `brand-tag` — это стиль).

## 6. Изображения

| Секция | Размер (рекомендуется) | Формат |
|---|---|---|
| Hero | 1920×1080, ≤ 300 КБ | JPG/WebP |
| Карточка новости | 800×600 | JPG/WebP |
| Карточка события | 800×600 | JPG/WebP |
| Печать | 800×600 | JPG/WebP |
| Логотип партнёра | SVG или PNG 200×80 | SVG/PNG |

Правила:

- `alt` — описание смысла, не «image1.jpg»;
- декоративные картинки — `alt=""`;
- ниже первого экрана — `loading="lazy"`;
- соотношение сторон сохраняется, иначе `object-fit: cover` обрежет важное.

Демо-изображения лежат в `assets/images/`. Заменяйте их на свои, сохраняя
имена, — тогда разметка не изменится. Либо загружайте через инфоблок.

## 7. SEO

Для каждой страницы:

- **Свойства страницы** → `TITLE` (до 60 символов);
- `description` (до 160 символов);
- `keywords` — не обязательны, Битрикс их не использует для ранжирования;
- ЧПУ: **Настройки → Настройки продукта → Сайты → Список сайтов → Изменить**
  → «Обработка ЧПУ» / настройки модуля «Инфоблоки» → «ЧПУ»;
- `robots.txt` — стандартный, с `Disallow: /bitrix/` и `Disallow: /*?`;
  `/upload/` и `/local/templates/` оставить открытыми для картинок и CSS;
- `sitemap.xml` — модуль «Поиск» → «Карта сайта»;
- микроразметка — по желанию (`Organization`, `Event`).

Заголовок H1 на странице один. На главной это `hero-title` первого слайда;
остальные слайды — тоже `<h1>` в демо, но для продакшена лучше оставить один
`<h1>`, а остальные заменить на `<p class="hero-title">` или `<h2>` —
иначе поисковик увидит 3 H1.

## 8. Меню и подвал

Меню `top` — 7 пунктов (см. `installation.md`, п. 4). Подвал — статический,
ссылки в `footer.php`:

- «Читателям»: подарочные наборы, события, услуги, сувениры, правила;
- «Услуги»: читальные залы, электронная библиотека, печать, экскурсии,
  обучение;
- контакты, подписка, соцсети;
- нижняя строка: политика, условия, карта сайта.

Ссылки на несуществующие страницы дают 404 — создайте разделы или уберите
пункты.

## 9. Мультиязычность

Шаблон использует `LANGUAGE_ID` и `SITE_DIR`, поэтому технически готов к
двум сайтам (`/` и `/en/`). Но:

- тексты в `header.php`/`footer.php` захардкожены по-русски;
- инфоблоки не имеют версий для разных языков;
- переключателя языка нет.

Полноценная мультиязычность — в `roadmap.md`. До её реализации не создавайте
второй сайт на этом шаблоне без доработки.

## 10. Контент-менеджеру: памятка

1. Новая новость: **Контент → Инфоблоки → Новости → Добавить** → заполнить
   название, анонс, картинку, дату → сохранить.
2. Проверить на сайте: карточка появилась, дата верная, ссылка открывается.
3. Если не появилось — **Сбросить кеш** на панели.
4. Не менять HTML-код страницы в режиме «HTML» без необходимости: сломается
   сетка.
5. Фото — не больше 300 КБ, иначе страница грузится медленно.
