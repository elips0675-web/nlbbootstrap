# AGENTS-bitrix — правила работы с админкой и ядром

## 1. Где что лежит

| Задача | Путь в админке |
|---|---|
| Выбрать шаблон сайта | Настройки → Настройки продукта → Сайты → Список сайтов → сайт → «Шаблон сайта» |
| Создать тип меню | Настройки → Настройки продукта → Сайты → Типы меню |
| Заполнить меню | Контент → Структура сайта → раздел → «Меню» |
| Создать раздел/страницу | Контент → Структура сайта → «Добавить раздел» / «Добавить страницу» |
| Инфоблоки | Контент → Инфоблоки → Типы инфоблоков / <тип> → <инфоблок> |
| Свойства страницы (SEO) | Страница → «Изменить страницу» → «Свойства страницы» |
| Очистить кеш | Настройки → Автокеширование → Очистить весь кеш |
| Почтовые события | Настройки → Настройки продукта → Почтовые события |
| Пользователи и группы | Настройки → Пользователи |
| Журнал событий | Настройки → Инструменты → Журнал событий |
| Переиндексация поиска | Поиск → Переиндексация |
| Проверка системы | Настройки → Проверка системы |

Файлы:

| Что | Путь |
|---|---|
| шаблон | `local/templates/nlb_bootstrap/` |
| компонентные шаблоны | `local/templates/nlb_bootstrap/components/bitrix/<компонент>/<шаблон>/` |
| пользовательский `init.php` | `local/php_interface/init.php` |
| настройки сайта | `bitrix/.settings.php` (не редактировать вручную без нужды) |
| публичные страницы | корень сайта (`/index.php`, `/news/index.php`, …) |

## 2. Что можно и нельзя

Можно:

- править файлы шаблона в `local/`;
- создавать компонентные шаблоны;
- создавать страницы и инфоблоки;
- менять тип меню и пункты;
- добавлять `init.php`-хуки, если без них не обойтись.

Нельзя:

- править `bitrix/modules/**` и `bitrix/templates/**` — потеряется при
  обновлении;
- править `assets/css/bootstrap.min.css` и `assets/js/bootstrap.bundle.min.js`
  точечно — только замена версии целиком;
- хранить в шаблоне пароли, ключи, токены;
- отключать `ShowHead()`/`ShowPanel()` без причины — сломается SEO и панель;
- удалять SVG-спрайт из `header.php` — пропадут все иконки;
- менять `SITE_TEMPLATE_PATH` на абсолютный путь сайта — сломается
  мультисайт.

## 3. Кеш — причина 80% «не применилось»

Порядок при любой правке:

1. Сохранить файл.
2. Админка → **Автокеширование → Очистить весь кеш**.
3. Публичная страница → `Ctrl+F5`.
4. Если не помогло — проверить, что правится тот шаблон, который выбран у
   сайта (иногда сайтов несколько).

Кеш компонентов (`MENU_CACHE_TIME`, `CACHE_TIME`) сбрасывается той же кнопкой.
Кеш браузера — `Ctrl+F5`, кеш CDN (если есть) — purge.

## 4. Безопасность при правках

- перед установкой/обновлением — бэкап файлов и БД;
- не выполнять `chmod 777`;
- не выводить `$_GET`/`$_POST` без `htmlspecialcharsbx()`;
- формы — с CAPTCHA и серверной проверкой;
- не логировать персональные данные читателей;
- не коммитить `.env`, дампы, ключи.

## 5. Типовые ошибки

| Ошибка | Последствие | Как правильно |
|---|---|---|
| Шаблон в `bitrix/templates/` | потеря при обновлении | `local/templates/` |
| `IBLOCK_ID` угадан | пустой список или чужие данные | взять ID в списке инфоблоков |
| `SET_TITLE => 'Y'` и `SetTitle()` | два заголовка/дубль H1 | что-то одно |
| Нет `CHECK_DATES => 'Y'` | в списке будущие/архивные | включить |
| `CACHE_TIME => 0` везде | нагрузка на БД | 3600 для списков |
| Меню без типа `top` | демо-меню в продакшене | создать тип и пункты |
| Ссылки на несуществующие страницы | 404 в меню | создать раздел или убрать пункт |
| Правка `styles.css` без очистки кеша | «не работает» | очистить кеш |
| `include` вместо `require` header | страница без шапки | `require $_SERVER['DOCUMENT_ROOT'].'/bitrix/header.php'` |
| Забыт `footer.php` | нет подвала и скриптов | подключить в конце |

## 6. Как добавить компонентный шаблон

1. Создайте каталог:
   `local/templates/nlb_bootstrap/components/bitrix/news.list/news_cards/`.
2. В нём — `template.php`:

```php
<?php
if (!defined('B_PROLOG_INCLUDED') || B_PROLOG_INCLUDED !== true) {
    die();
}
$this->setFrameMode(true);
// разметка на $arResult['ITEMS']
```

3. В вызове компонента укажите имя шаблона вторым аргументом:
   `IncludeComponent('bitrix:news.list', 'news_cards', [...])`.
4. Очистите кеш.
5. Проверьте в режиме правки: у карточек есть иконки редактирования
   (`AddEditAction`).

## 7. Как подключить страницу

Минимальный шаблон страницы:

```php
<?php
require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/header.php';

$APPLICATION->SetTitle('Новости');
$APPLICATION->SetPageProperty('description', 'Новости библиотеки.');

// контент или компонент
?>

<div class="container section">
    <h1><?php $APPLICATION->ShowTitle(false); ?></h1>
    ...
</div>

<?php require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/footer.php'; ?>
```

`ShowTitle(false)` выводит заголовок без тега `<title>` (он уже в
`header.php`). Если заголовок не нужен в контенте — не вызывайте.

## 8. Чек-лист перед сдачей

- [ ] шаблон выбран у сайта, кеш очищен;
- [ ] тип `top` создан, демо-меню не показывается;
- [ ] все ссылки меню/подвала ведут на существующие страницы;
- [ ] формы подключены к компонентам, письма уходят;
- [ ] контакты и реквизиты — реальные;
- [ ] `php -l` без ошибок (на сервере);
- [ ] `node tools/check-template.mjs` и `node tools/check-docs.mjs` — exit 0;
- [ ] `Что доделать.txt` не содержит закрытых пунктов;
- [ ] `Что сделано.txt` содержит запись об этапе.
