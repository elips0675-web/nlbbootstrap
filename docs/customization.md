# Кастомизация шаблона

Все правки — в `local/templates/nlb_bootstrap/`. После каждой правки PHP —
очистить кеш Битрикса; после CSS/JS — обновить страницу с `Ctrl+F5`.

## 1. Логотип и название

Сейчас логотип — SVG-иконка книги в градиентном квадрате (`header.php:116`,
`footer.php:18`).

### Вариант A: заменить иконку

В `header.php` и `footer.php` найдите:

```html
<span class="brand-mark">
    <svg class="i" aria-hidden="true"><use href="#i-book"/></svg>
</span>
```

Замените на свой SVG:

```html
<span class="brand-mark">
    <img src="<?= SITE_TEMPLATE_PATH ?>/assets/images/logo.svg" alt="" width="24" height="24">
</span>
```

Или уберите `.brand-mark` и поставьте готовый логотип:

```html
<a class="brand" href="<?= SITE_DIR ?>">
    <img src="<?= SITE_TEMPLATE_PATH ?>/assets/images/logo.svg" alt="Библиотека 2026" height="46">
</a>
```

### Вариант B: только текст

```html
<span>
    <span class="brand-name">Название библиотеки</span>
    <span class="brand-tag">Центр знаний</span>
</span>
```

`brand-tag` — маленькая подпись капсом. Не удлиняйте её больше 22 символов:
на мобильном перенесётся.

## 2. Палитра

Цвета — в `styles.css:12`. Меняйте значения, а не имена переменных:

```css
:root {
    --nlb-primary: #0f766e;       /* было #2563eb */
    --nlb-primary-dark: #115e59;
    --nlb-violet: #0d9488;
    --nlb-violet-bright: #14b8a6;
    --nlb-grad: linear-gradient(135deg, #0f766e 0%, #0d9488 55%, #14b8a6 100%);
}
```

Проверьте после замены:

- белый текст на `.btn-nlb` читается (контраст ≥ 4.5:1 для мелкого);
- `.text-gradient` не стал светлым на белом;
- иконки в `.icon-tile` не сливаются с фоном (у них свои модификаторы —
  `--blue`, `--green` и т.д.);
- бейджи событий (`bg-grad-*`) остаются различимыми.

Если меняете только акцент (кнопки/ссылки), достаточно `--nlb-primary`,
`--nlb-primary-dark` и `--nlb-grad`. Остальные градиенты можно не трогать.

## 3. Шрифт

По умолчанию внешних шрифтов нет: в `styles.css:53` стоит системный стек

```css
font-family: "Manrope", "Inter", "Segoe UI", system-ui, -apple-system, "Helvetica Neue", Arial, sans-serif;
```

`Manrope` подхватится, если он установлен в системе; иначе используется
системный шрифт. Это быстрее (нет DNS/TLS к Google), приватнее и работает
офлайн.

### Локальный Manrope (если нужен именно он)

1. Скачайте WOFF2 (400, 600, 700, 800) и положите в `assets/fonts/`.
2. Добавьте в начало `styles.css`:

```css
@font-face {
    font-family: "Manrope";
    src: url("assets/fonts/manrope-400.woff2") format("woff2");
    font-weight: 400;
    font-display: swap;
}
/* … повторить для 600, 700, 800 */
```

Путь в `@font-face` относительный от `styles.css`, поэтому `assets/fonts/…`
без ведущего слэша.

## 4. Контакты

Демо-контакты встречаются в трёх местах:

| Место | Строки |
|---|---|
| Топбар | `header.php:80–102` |
| Подвал | `footer.php:75–90` |
| FAB | `footer.php:117–143` |

Замените:

- `+375 (17) 300-00-00` → реальный телефон (в `tel:` — только цифры и `+`);
- `info@example.by` → реальный e-mail;
- `Минск, пр. Независимости, 116` → адрес;
- `Ежедневно 10:00–22:00` → режим работы;
- `220114` → индекс.

Телефон в `tel:` и в тексте должен совпадать, иначе часть посетителей
позвонит не туда.

## 5. Соцсети

`footer.php:30–43`: Telegram, VK, Instagram, YouTube.
`footer.php:119–126`: Telegram и WhatsApp в FAB.

Замените `https://t.me/example`, `https://vk.com/example` и т.д. на реальные
аккаунты. Ссылки открываются в новой вкладке и имеют
`rel="noopener noreferrer"` — не удаляйте это.

Если соцсети нет — удалите ссылку целиком, а не оставляйте `href="#"`.

## 6. Меню

Состав — в админке (**Структура сайта → Меню**, тип `top`), не в коде.
Порядок — поле «Сортировка» (10, 20, 30…). Вложенность — «Уровень»:
при `MAX_LEVEL => '1'` второй уровень не выводится.

Чтобы включить выпадающее меню:

1. В `header.php:125` поставьте `'MAX_LEVEL' => '2'`.
2. В шаблоне `top_bootstrap` добавьте разметку `dropdown` — сейчас шаблон
   выводит плоский список.
3. Создайте пункты второго уровня в админке.

Без правки шаблона второй уровень просто не отрисуется.

## 7. Подвал

- Колонки «Читателям» и «Услуги» — `footer.php:45–67`;
- блок контактов и подписка — `footer.php:69–108`;
- нижняя строка — `footer.php:105–112`;
- реквизиты — модалка `footer.php:190`.

Ссылки ведут на разделы; если раздела нет — 404. Создайте страницу или
уберите пункт.

## 8. Подписка и обратная связь

Демо-форма подписки (`footer.php:92`) отправляет `EMAIL` на `/subscribe/`.
Демо-форма обратной связи (`footer.php:149`) — на `/feedback/`.
Рабочая интеграция — `bitrix-integration.md`, п. 7–8.

Пока компоненты не подключены, формы будут отправлять POST на несуществующие
страницы (404) — это ожидаемо для демо, но не для продакшена.

## 9. Hero-слайды

Разметка — `demo/index.php` (секция `#top`). Чтобы добавить слайд:

1. Скопируйте блок `<div class="carousel-item">…</div>`.
2. Замените картинку (`assets/images/hero-N.jpg`), заголовок, текст, ссылку.
3. Добавьте кнопку-индикатор:

```html
<button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="3" aria-label="Слайд 4"></button>
```

4. Проверьте, что количество индикаторов совпадает с количеством слайдов.

Интервал — `data-bs-interval="7000"` (7 секунд) на `.carousel`.

## 10. Секции главной

Порядок секций — в `demo/index.php`/`index.php`. Каждая секция — `<section
class="section" id="…">`. Чтобы скрыть секцию, удалите её целиком (не
оставляйте пустой `<section>` — останется отступ).

Чтобы добавить новую секцию:

```html
<section class="section section--soft" id="new-section">
    <div class="container">
        <div class="section-head" data-reveal>
            <span class="eyebrow eyebrow--green">Надзаголовок</span>
            <h2 class="section-title">Заголовок</h2>
            <p class="section-lead">Подзаголовок.</p>
        </div>
        <div class="row g-4">
            <div class="col-md-6" data-reveal>…</div>
        </div>
    </div>
</section>
```

`data-reveal` включает анимацию появления (если не отключена в системе).

## 11. Цвет шапки и топбара

- топбар: `.topbar` (`styles.css:360`) — фон `#0b1220`;
- шапка: `.site-header` (`styles.css:382`) — полупрозрачный белый с blur;
- при скролле: `.site-header.is-scrolled`.

Если нужна непрозрачная шапка, уберите `backdrop-filter` и поставьте
`background: #fff`.

## 12. Дочерний шаблон

Если правок много и хочется сохранить оригинал:

1. Скопируйте `nlb_bootstrap` в `nlb_bootstrap_child`.
2. В `.description.php` поменяйте `NAME`.
3. Выберите дочерний шаблон у сайта.

Наследования, как в Twig/Blade, в Битриксе нет: дочерний шаблон — полная
копия. Обновлять придётся оба.

## 13. Что не менять

- `assets/css/bootstrap.min.css`, `assets/js/bootstrap.bundle.min.js` — только
  замена версии целиком;
- SVG-спрайт в `header.php` — при удалении символов пропадут иконки;
- `script.js` — модули независимы, но порядок и IIFE лучше сохранить;
- `demo/index.php` — это демо, для продакшена делайте свою главную.

## 14. Чек-лист после кастомизации

- [ ] логотип не размывается на retina (SVG или 2x PNG);
- [ ] телефон кликабелен и совпадает с текстом;
- [ ] соцсети ведут на реальные аккаунты;
- [ ] меню содержит только существующие страницы;
- [ ] формы отправляются на существующие обработчики;
- [ ] контраст кнопок и текста проверен;
- [ ] мобильная версия 360px не ломается;
- [ ] кеш очищен, правки видны.
