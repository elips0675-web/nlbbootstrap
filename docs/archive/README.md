# Архив

Здесь лежат документы, которые **перестали быть источником правды**. Они
сохраняются для истории, но на них нельзя ссылаться как на правило.

## Что сюда попадает

- старые варианты установки (CDN-подключение Bootstrap, шаблон в
  `bitrix/templates/`);
- отвергнутые макеты и палитры;
- черновики текстов и SEO-описаний;
- скриншоты «до/после» для регресса;
- заметки сессий, которые не стали правилом.

## Что сюда не попадает

- действующие инструкции — они в `docs/`;
- бэклог — `Что доделать.txt`;
- журнал — `Что сделано.txt`.

## Индекс

Пока пуст. Первая запись появится, когда будет заменён первый рабочий
документ. Формат записи:

```
## <дата> — <что архивировано>
Причина: …
Замена: <ссылка на актуальный документ>
Файл: <имя>
```
