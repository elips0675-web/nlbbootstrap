# Дизайн-система

Дизайн-система шаблона — это CSS-переменные (`styles.css:12`) и набор
повторяемых классов. Всё, что не описано здесь, считается локальной разметкой
страницы.

Правила:

- **текст на цветном фоне** — только белый или `--nlb-ink`; зелёный/голубой
  фон с белым текстом допустим на кнопках (крупный жирный), но не для мелкого
  текста;
- **не вводить новый HEX в разметку.** Новый оттенок — новая переменная в
  `:root` с комментарием, где применяется;
- **контраст проверяется** для текста ≥ 4.5:1, для крупного (≥ 18.66px bold
  или ≥ 24px) — ≥ 3:1.

## 3. Отступы и радиусы

Шкала — шаг 0.25rem (как в Bootstrap). Основные значения:

| Токен/класс | Значение | Где |
|---|---|---|
| `.section` | `padding: 5.5rem 0` | секция десктоп |
| `.section--tight` | `3.5rem 0` | компактная секция |
| `.section` (≤ 991px) | `4rem 0` | планшет |
| `.section` (≤ 767px) | `3.25rem 0` | мобильный |
| `.section-head` | `margin-bottom: 3rem` | заголовок секции |
| `.nlb-card__body` | `padding: 1.4rem` | карточка |
| `--nlb-radius` | `1.25rem` | карточки, секции |
| `--nlb-radius-sm` | `0.85rem` | поля, мелкие блоки |
| `.btn` | `border-radius: 999px` | все кнопки |

Радиусы не смешиваются в одном блоке: карточка — `1.25rem`, поле внутри —
`0.85rem`, кнопка — «таблетка».

## 4. Компоненты

### Кнопки

| Класс | Вид | Где |
|---|---|---|
| `.btn-nlb` | сине-фиолетовый градиент, белый текст | основное действие |
| `.btn-nlb-green` | зелёный градиент | hero CTA, «все услуги» |
| `.btn-nlb-sky` | голубой градиент | каталог печати |
| `.btn-nlb-white` | белая на цветном фоне | CTA-баннер |
| `.btn-nlb-outline` | белая с бордером | вторичное действие |
| `.btn-sm-nlb` | уменьшенные паддинги | шапка |
| `.btn-lg-nlb` | увеличенные паддинги | hero, CTA |
| `.btn-icon` | flex + gap для иконки | кнопка с SVG |

Все кнопки — `<a>` или `<button>` с классами `btn` + модификатор. Иконка —
справа, 1.25em, `aria-hidden="true"`.

Нельзя: `.btn-primary` без переопределения (будет синий Bootstrap, не наш
градиент), кнопка без `type` внутри формы (по умолчанию `submit`).

### Карточки

| Класс | Что | Сетка |
|---|---|---|
| `.service-card` | услуга с иконкой-плиткой | 1 / 2 / 3 |
| `.print-card` | печатная услуга в скроллере | 1 / 2 / 3 / 4 |
| `.nlb-card` | событие или новость | 1 / 2 / 3–4 |
| `.collection-card` | коллекция с числом | 1 / 2 / 3 |
| `.partner` | логотип партнёра | 2 / 3 / 5 |

Общее: `height: 100%`, бордер `--nlb-line`, радиус `--nlb-radius`,
hover-подъём `translateY(-6px)` и тень `--nlb-shadow`. Внутри карточки
картинка масштабируется `scale(1.06–1.07)` за 0.55s.

Картинки выводятся через `nlb_picture()` (`local/php_interface/include/nlb_media.php`):
`<picture class="nlb-picture">` с AVIF и WebP, JPG-фолбэком и `srcset`.
Обёртка имеет `display: contents`, своей коробки не создаёт — `img` остаётся
прямым участником раскладки, селекторы `.nlb-card__media img`, `.hero-img`,
`.print-media img` работают как раньше.

### Плавающие виджеты

`.fab` — кнопка «+» с меню быстрой связи (Telegram, WhatsApp, звонок, e-mail,
форма обратной связи, «ИИ-помощник»). Пункты — `.fab-item` с кружком
`.fab-ico--*`; на узком экране подписи визуально скрыты, остаются иконки.

`.nlb-chat` — окно ИИ-помощника, которое открывает последний пункт меню.
Панель `position: fixed` над кнопкой «+» (`bottom` считается от высоты FAB
плюс `--nlb-notice-h`), шапка на `--nlb-grad`, лента `.nlb-chat__log`,
пузыри `.nlb-chat__msg--bot` / `--user`, быстрые ответы `.nlb-chat__chip`.
Логика — `script.js`, раздел 4.1: правила вместо модели, `USE_REAL_AI`
переключает на бэкенд. Правила покрывают десять тем: часы работы, адрес
и как добраться, услуги и пространства, бронирование залов, афишу, печать,
читательский билет, книги и поиск, Wi-Fi и электронные ресурсы, контакты.
Если совпадения нет, бот предлагает отправить вопрос библиотекарю:
`askQuestion()` закрывает чат и открывает `#feedbackModal`, подставляя
текст вопроса в поле `MESSAGE`. Та же ссылка `.nlb-chat__link` есть под
формой в блоке `.nlb-chat__hint`; рядом с ней — «Скопировать диалог»
(`data-chat-copy`). `chatTranscript()` собирает ленту в текст «Вы: …» /
«ИИ-помощник: …», пропуская индикатор «печатает», `copyChat()` пишет его
через `navigator.clipboard.writeText`, а при отсутствии API или отказе —
через скрытую `textarea` и `execCommand('copy')`. Обратная связь — статус
в шапке на 1,8 с («диалог скопирован» / «не удалось скопировать»),
возвращается к прежнему только если его не перебили. На ширине ≤575.98px
панель растягивается по экрану.

Голосовой ввод — круглая кнопка-микрофон `#nlbChatMic` рядом с отправкой
(34×34, иконка `#i-mic`). Она скрыта атрибутом `hidden` и показывается
только при наличии `SpeechRecognition`/`webkitSpeechRecognition`: там, где
API нет, интерфейс остаётся прежним. Распознавание идёт на `ru-RU` без
промежуточных результатов; текст не затирает набранное, а добавляется
к нему через пробел, пустая строка игнорируется. Пока идёт запись, кнопка
получает `is-listening` (красный фон и пульсация), `aria-pressed="true"`
и подпись «Остановить голосовой ввод»; повторный клик останавливает.
Ошибки («нет доступа к микрофону», «не расслышал», прочие сбои)
показываются в строке `#nlbChatError`, но поле не помечается невалидным.
Запись останавливается при закрытии чата и при «Назад».

Прокрутка ленты не всегда идёт вниз. `chatNearBottom()` проверяет, у конца
ли ленты пользователь (порог 48 px): если он читает выше, приход ответа
вид не двигает. Своё сообщение прокручивает всегда — `addChatMessage()`
передаёт `force: who === 'user'`. Ответ выше окна ленты
(`row.offsetHeight > chatLog.clientHeight`) показывается с начала: лента
встаёт так, чтобы верх пузыря был в 8 px от верха, иначе длинные ответы
про услуги и афишу открывались бы с конца. Индикатор «печатает»
и быстрые ответы считают то же состояние до вставки, «Назад» сбрасывает
ленту в начало.

В шапке есть кнопка «Развернуть чат» (`data-chat-expand`, 32×32, иконки
`#i-expand` / `#i-collapse`). Она переключает класс `is-expanded`: панель
встаёт на весь экран (`inset: 0`, `z-index: 1055` — выше кнопки «+»),
а лента, форма и подсказка ограничивают ширину текста 900 px по центру.
Кнопка меняет `aria-pressed`, подпись и иконку. При закрытии чата разворот
сбрасывается — следующее открытие всегда обычного размера.

Длинные ответы не выкладывают всё сразу: у шести правил есть поле `more`,
и хвост (расписание и бронирование услуг, запись на события, каталог
печати, регистрация, подборки) лежит в том же пузыре под кнопкой
«Подробнее». Блок `.nlb-chat__more` скрыт атрибутом `hidden`, кнопка
`.nlb-chat__more-btn` связана с ним через `aria-controls` и держит
`aria-expanded`; клик раскрывает детали на месте и меняет подпись
на «Свернуть», повторный — прячет. Новых фактов нет: хвост перенесён
из прежних ответов дословно. Ответы без `more` кнопки не получают.

Под ответом может появиться одна короткая маркетинговая подсказка —
`.nlb-chat__promo`: строка с мягким фоном и зелёной полосой слева,
кегль 0.76rem, в конце — ссылка на страницу услуги. Это не рекламный
блок и не второй пузырь: текст идёт сразу под ответом, после «Источника»
и перед оценкой, ленту не перекрывает. Подсказки лежат в `PROMOS`
(`script.js`), тема подбирается по вопросу, а показ ограничен: не больше
трёх за сеанс, первая не раньше второго вопроса, дальше не чаще чем через
три, одна и та же не повторяется, про услугу из самого вопроса не
предлагается, в ответе про оператора и жалобу — никогда (`promo: false`
у правила). «Назад» сбрасывает счётчики. Пример тона: «Кстати, если
хотите быть в форме — у нас спортзал от 1000 ₽/месяц. Дешевле, чем
фитнес-клуб, и без очереди к беговой дорожке 💪». Тексты — демо,
их согласует библиотека (P2-8).

Проактив сделан пузырём, а не раскрытой панелью: через 8 секунд после
загрузки над кнопкой «+» появляется `#nlbChatPrompt` — «Нужна помощь?
Спросите ИИ-помощника» и крестик. Показ один раз за сессию: отметка
`nlbChatPrompt` в `sessionStorage` ставится в момент появления, поэтому
перезагрузка вкладки пузырь не возвращает; если чат уже открывали
(`chatStarted`), подсказка не показывается. Клик открывает чат
и прячет пузырь, крестик просто скрывает.

Кнопка отправки должна быть кликабельной, а не только `Enter`. У `.fab`
`z-index: 1045`, у `.nlb-chat` — `1044`, при этом контейнер меню занимает
место пунктов и тогда, когда они скрыты (`visibility: hidden`), поэтому он
накрывал `.nlb-chat__send`: клик уходил в `.fab-menu`, сообщение не уходило,
и фильтр не срабатывал. Решение — `pointer-events: none` у `.fab`
и `.fab-menu`; интерактивны только `.fab-toggle` и видимые пункты
(`.fab.is-open .fab-item`, `pointer-events: auto`). Кнопка «+» стоит ниже
панели по `bottom`, а меню, открытое при открытом чате, по-прежнему
раскрывается поверх панели и остаётся кликабельным.

Приветствие зависит от страницы: `pageSection()` смотрит `location.pathname`
и относит страницу к разделу — услуги, печать, афиша, новости, книги
и подборки, контакты, обратная связь. `sectionGreeting()` возвращает для
каждого раздела свой текст и свой набор быстрых ответов; на остальных
страницах — общее приветствие и шесть кнопок. Подписи кнопок подобраны
так, чтобы попадать в правила `RULES` («Забронировать зал» — бронирование,
«Визитки» — печать, «Поиск по каталогу» — книги), иначе клик приводил бы
к ответу «не нашёл». Приветствие подставляется и при первом открытии,
и после кнопки «Назад» — `resetChat()` вызывает тот же `greetChat()`.

Шапка чата: имя и роль слева, круглый аватар справа от текста
(`assets/images/avatar-tatyana.svg`, 46px, обрезан по кругу), крестик
последним. Заголовок — «Татьяна Петровна», статус — «ИИ-помощник
ТП НББ · онлайн». Аватар — векторная иллюстрация, а не фотография:
это персонаж-помощник, а не сотрудник библиотеки. Имя и картинка
оставлены по решению владельца шаблона и требуют согласования
с библиотекой (P1-15).

Кнопка «Назад» (`.nlb-chat__back`, `data-chat-back`) видна сразу и
возвращает в начало диалога — `resetChat()` очищает ленту, снимает
предупреждение фильтра и заново показывает приветствие с быстрыми
ответами. Отложенные ответы отменяются: `chatLater()`
запоминает номер прогона `chatRun`, `resetChat()` его увеличивает, поэтому
таймеры прошлой переписки не дописывают сообщения в новую ленту.
На ширине ≤575.98px подпись «Назад» скрыта — остаётся стрелка, иначе имя
и роль переносились на две строки; доступное имя задаёт `aria-label`
(«Вернуться в начало диалога»).

Живого оператора в демо нет: быстрые ответы «Написать библиотекарю»
и правило про оператора ведут в форму обратной связи (`askQuestion()`),
а не в имитацию переписки. Правило отвечает честно: «Живого оператора
в этом демо нет: отвечает виртуальный помощник по правилам сайта»,
и предлагает оставить вопрос или позвонить. Приветствие после `resetChat()`
прокручивается к началу, чтобы был виден текст, а не только кнопки.

Под ответом бота есть строка «Источник: …» (`.nlb-chat__src`): каждое
правило `RULES` несёт `links` — путь раздела и подпись, например
`{ path: 'printing/', label: 'Печать' }`. Путь не собирается из строки
вручную: `chatHref()` ищет в документе уже готовую ссылку, которая
заканчивается на этот путь (навигация, подвал), и берёт её префикс. Поэтому
в шаблоне ссылка получает `SITE_DIR`, а в статическом превью — нужное
число `../`: на главной `services/`, на `/services/cafe/` — `../../printing/`.
Если подходящей ссылки в документе нет, путь используется как есть. Ответ
«не нашёл» ведёт в «Контакты». Так видно, откуда взят факт, — это первый
пункт UX-списка P2-7.

Ответ можно оценить: под пузырём две круглые кнопки 25×25 с иконками
`#i-thumb-up` и `#i-thumb-down` (`.nlb-chat__rate-btn`, `aria-label`
«Ответ полезен» / «Ответ не полезен», `aria-pressed`). Приветствие
и служебные реплики оценки не получают — только ответ правила и ответ
«не нашёл». После клика группа получает `is-rated`:
выбранная кнопка подсвечивается градиентом, обе становятся `disabled`,
рядом появляется «Спасибо, учту» или «Спасибо, попробую иначе». Оценка
пишется в `localStorage` под ключом `nlbChatRating` — массив
`{ q, a, v, t }` (вопрос, первые 120 символов ответа, 1 или −1, время),
хранятся последние 50 записей. Запись обёрнута в `try/catch`: в приватном
режиме и при запрете хранилища чат продолжает работать, просто оценка
не сохраняется. Серверной аналитики нет — это задел под неё (P2-7 п.4).

Перед отправкой сообщение проверяет `chatProblem()` (образец —
`src/lib/word-filter.ts` в SwiftMatch, перенесён без TypeScript и без
зависимостей). Три причины отказа: `rude` — мат, оскорбления, реклама
и «запрещённые товары»; `spam` — ссылки (`http`, `www.`, `t.me/`,
`vk.com/`, свои домены `nlb.by` и `example.by` разрешены); `gibberish` —
бессмыслица (повтор символов, мало разных букв, слово без гласных,
6 согласных подряд, клавиатурные последовательности, тройной повтор
триграммы). Отказ не отправляет сообщение: текст остаётся в поле,
под формой появляется `.nlb-chat__error` с `role="alert"`, у поля
`aria-invalid="true"` и класс `.is-invalid`; ввод следующего символа
убирает предупреждение.

Список корней адаптирован под библиотеку, а не скопирован целиком:
сняты политика («война», «президент» — иначе блокируются «Война и мир»
и «Библиотека Президента»), конкуренты дейтинг-сервисов и корни с ложными
срабатываниями на книжных словах (`муд` → «мудрый», `жид` → «жидкий»,
`закладк` → «закладка», `секс` → «секция», `уби` → «убирать», `ставк` →
«вставка»). Тематические корни (`террор`, `насил`, `оружи`, `нарко`,
`порно`, `секс`, `убий`) пропускаются, если в сообщении есть книжный
контекст (`CHAT_STUDY`: «книг», «роман», «учебник», «история», «каталог»
и т. п.) — иначе нельзя было бы спросить книги по истории. Это фильтр
интерфейса, а не защита: на боевом сайте та же проверка нужна на сервере
(P1-17).

### Иконки-плитки

`.icon-tile` — 64×64, радиус 18px, градиентный фон, цветная иконка 30px.
Модификаторы: `--blue`, `--violet`, `--green`, `--orange`, `--sky`.
В коллекциях плитка уменьшена до 56×56 и выровнена влево
(`styles.css:1063`).

### Бейджи и надзаголовки

`.eyebrow` — «таблетка» с фоном; модификаторы `--green`, `--red`, `--violet`.
`.event-cat` — цветной бейдж на картинке события. `.print-badge` — квадратная
иконка 46×46 на карточке печати.

### Скроллер

`.scroller` — `display: flex`, `overflow-x: auto`, `scroll-snap-type: x
mandatory`, скрытый скроллбар. Карточки `flex: 0 0 84%` на мобильном, далее
50% / 33% / 25%. Кнопки `.scroller-btn` скрыты на ≤ 575px — листается пальцем.

### Формы

`.form-control`, `.form-select` — радиус 0.85rem, бордер `--nlb-line`,
focus — голубое кольцо. `.form-label` — 0.9rem, вес 700. `.form-hint` —
0.8125rem, `--nlb-muted`. В подвале поля инвертированы (`.newsletter`).

### Модалки

`.modal-nlb` — радиус 1.5rem, тень, заголовок 1.15rem, тело 1.5rem.
Используется для поиска, обратной связи и реквизитов.

### FAB и «наверх»

`.fab` — фиксированный справа снизу, раскрывается по клику, пункты появляются
каскадом (transition-delay 0.03–0.15s). `.to-top` — слева снизу, появляется
после 480px прокрутки.

## 5. Состояния

| Состояние | Класс/селектор | Где |
|---|---|---|
| Наведение | `:hover` | карточки, кнопки, ссылки |
| Фокус | `:focus-visible` | всё, глобально |
| Активный пункт | `.active` + `aria-current` | меню |
| Шапка при скролле | `.is-scrolled` | `header` |
| FAB открыт | `.is-open` | `.fab` |
| Появление | `.is-visible` | `.reveal` |
| Ошибка формы | `.was-validated` + `:invalid` | Bootstrap |

Переходы — 0.18–0.3s, `ease`. При `prefers-reduced-motion: reduce` отключены.

## 6. Как добавить новый компонент

1. Проверьте, нет ли готового класса (таблица выше).
2. Соберите блок на утилитах Bootstrap.
3. Если повторяется — добавьте класс в `styles.css` в конец нужного раздела,
   с комментарием.
4. Цвета — только через `var(--nlb-*)`.
5. Адаптив — в разделе 14 `styles.css`, не в `<style>` на странице.
6. Состояния — `is-*`, не `active` (кроме меню).
7. Проверьте: мобильная ширина 360px, планшет 768px, десктоп 1440px.
8. Добавьте пример в `preview/index.html`, если компонент публичный.

## 7. Чего не делать

- Не менять `--nlb-*` точечно на одной странице — сломается вся система.
- Не использовать Tailwind-классы (`text-slate-600`, `rounded-2xl`) — их нет.
- Не копировать стили из исходного React-макета «как есть»: там Tailwind,
  здесь Bootstrap + CSS.
- Не добавлять вторую систему кнопок/карточек «рядом» — расширяйте текущую.
- Не задавать фиксированную высоту карточкам: контент разной длины.
